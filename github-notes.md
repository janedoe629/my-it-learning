# GitHub Learning Notes

## Git and GitHub
Git tracks changes to project files.
GitHub is an online service where I can store Git repositories and share projects.

## Repository
A repository is a project folder containing files and their change history.

## README
A README introduces a project and explains what the repository contains.

## Commit
A commit records a set of changes in the repository's history.
A commit message describes what changed.

## .gitignore
A .gitignore file tells Git which untracked files or folders to ignore.
It does not remove files that Git already tracks.

## What I Practiced
- Creating a repository
- Editing a README
- Saving changes with a commit
- Creating a Markdown file
